# Logo assets

Drop the 6 brand logo image files in this folder using the **exact filenames** below. The HTML pages in `index.html` and `resume.html` already reference these paths, so the moment you upload a file the page will pick it up — no code changes needed.

## Required filenames

| File | Logo |
|------|------|
| `gcp.png` | Google Cloud Platform |
| `azure.png` | Microsoft Azure |
| `pmi.png` | PMI / PMP |
| `iim-bangalore.png` | IIM Bangalore |
| `iit-madras.png` | IIT Madras |
| `uptu-lucknow.png` | UPTU / AKTU Lucknow |

## Tips

- **Recommended format:** PNG with a transparent background, or SVG (rename `.svg` → `.png` is fine — browsers don't actually check extension; or update the `src` attribute in HTML to use `.svg`).
- **Recommended size:** 256×256 px or larger, square. The CSS sizes them down to 44×44 with `object-fit: contain` so they always fit without distortion.
- **Source:** download from each brand/institution's official site or press kit. Examples:
  - Google Cloud — https://cloud.google.com/press
  - Microsoft Azure — https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks
  - PMI — https://www.pmi.org/about/press-media/logo-usage
  - IIM Bangalore — https://www.iimb.ac.in/
  - IIT Madras — https://www.iitm.ac.in/
  - AKTU/UPTU Lucknow — https://aktu.ac.in/

## Upload via GitHub web UI (easiest path)

1. Open this folder on GitHub: `https://github.com/anadiazure/MyProfile/tree/<branch>/assets/logos`
2. Click **Add file** → **Upload files**
3. Drag the 6 logo files in (rename them to match the filenames above before or after upload)
4. Commit directly to the branch
5. Refresh your portfolio page — logos appear immediately
